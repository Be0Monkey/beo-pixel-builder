# Sprite Builder Studio

Application Windows 11 locale (Python + PySide6), sans IA, pour assembler des sprites 2D en vue 3/4.
Spécifications complètes : `docs/specs/` (commencer par `04_Plan_de_developpement_Claude.md`).

## Lancer
```
pip install -e .[dev]
python -m sbs
```

## Tester
```
python -m pytest
```

## État
Jalon **J0** (socle) : fenêtre, panneaux enregistrables, préférences, identifiants UUID. Rien d'autre n'est implémenté.
